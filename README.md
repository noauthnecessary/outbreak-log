# Outbreak Log

Where Leon, Claire, Jill and Carlos were in Raccoon City, hour by hour, combining the Resident Evil 2 (2019) and Resident Evil 3 (2020) remakes on one clock.

Interactive map with a time slider, playback, confidence tags for every event, time and place, and layer toggles for inferred and speculative locations.
